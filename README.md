# Цех — Telegram Mini App

Обучающая платформа с короткими курсами: код, AI, бизнес, ремесло, лайфхаки.
Приложение открывается внутри Telegram, но полностью работает и в обычном браузере.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run lint
```

## Как это устроено

Зависимости идут строго в одну сторону:

```
экраны → модули (catalog, library, settings) → платформа (telegram, storage)
              ↘ компоненты (ui, layout, course, lesson) ↗
```

| Папка | За что отвечает |
|---|---|
| `src/app` | Точка входа, роутер, палитра (`theme.css`, `colors.ts`) |
| `src/platform/telegram` | Обёртка над Telegram WebApp SDK: BackButton, MainButton, Haptics, вьюпорт |
| `src/platform/storage` | Асинхронное key-value: Telegram CloudStorage или localStorage |
| `src/modules/catalog` | Курсы, категории, уроки. Единственная дверь к данным — `catalog.repository` |
| `src/modules/library` | Личное: закладки и прогресс. Знает только идентификаторы |
| `src/modules/settings` | Настройки приложения |
| `src/data` | Моковый контент |
| `src/components` | UI-кит, layout, карточки курсов, рендер блоков урока |
| `src/screens` | Шесть экранов приложения |

Ключевое разделение: **library не знает содержимого курсов**, только их `id`.
Сшивают их экраны — например, «Сохранённое» берёт список id из library
и запрашивает по нему курсы у catalog.

## Поведение интерфейса

- Таб-бар виден на всех экранах, включая курс и урок (ADR 0007).
- На экране шире `md` приложение рисуется колонкой в 440px по центру —
  ширина задаётся переменной `--app-width`.
- Настройка «Меньше анимации» в профиле ставит `data-motion="reduced"`
  на `<html>`; системный `prefers-reduced-motion` учитывается тоже.
- Опасные действия подтверждаются прямо в строке. Нативный `confirm()`
  использовать нельзя — он блокирует WebView Telegram.

## Что где менять

- **Добавить курс** — `src/data/courses.ts`, уроки в `src/data/lessons.ts`.
  В режиме разработки консоль предупредит, если число уроков или сумма их
  длительностей разойдётся с тем, что заявлено в карточке курса.
- **Подключить настоящий API** — `src/modules/catalog/catalog.repository.ts`. Экраны не трогать.
- **Новый тип контента в уроке** (видео, тест) — добавить вариант в `LessonBlock`
  и ветку в `src/components/lesson/BlockRenderer.tsx`.
- **Цвета** — `src/app/theme.css` (для CSS) и `src/app/colors.ts` (для JS).
- **Ширина колонки на ПК** — переменная `--app-width` в `src/app/theme.css`.

## Решения по архитектуре

Записаны в `docs/decisions/`. Каждое объясняет контекст, выбор, цену выбора
и что рассматривали ещё. Читать перед тем, как что-то переделывать.

## Деплой

Проект развёрнут на Vercel и пересобирается сам при пуше в `main`:
**https://data-tseh.vercel.app**

Настройки лежат в `vercel.ts`: фреймворк Vite, сборка `npm run build`,
вечный кэш для файлов из `assets` (их имена содержат хеш содержимого).
Заголовки, ограничивающие встраивание в iframe, намеренно не заданы —
Telegram Desktop открывает мини-апп именно в iframe.

## Публикация в Telegram

1. Взять адрес деплоя (или свой домен на HTTPS).
2. В [@BotFather](https://t.me/BotFather): `/newapp`, указать URL мини-аппа.
3. Приложение использует HashRouter — настройка rewrite на хостинге не нужна.

## Известные ограничения

- Прогресс живёт в Telegram CloudStorage, аналитики по нему нет — нужен бэкенд.
- Обложки курсов рисуются CSS-градиентами: настоящих картинок пока нет.
- Мультиязычности нет, все тексты русские.
- Уроки написаны для пяти курсов — по одному в каждом направлении:
  «Git без страха», «Промпты, которые работают», «Юнит-экономика на салфетке»,
  «Кофе как в спешелти», «Горячие клавиши macOS». Остальные восемь показывают
  честную заглушку.
