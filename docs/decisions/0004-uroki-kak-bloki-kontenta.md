# 0004. Урок — это список блоков контента, не видео

**Дата:** 2026-08-24
**Статус:** принято

## Контекст
Изначально уроки планировались видео. Заказчик уточнил: видео не будет,
только текст и картинки.

## Решение
`Lesson` содержит поле `blocks: LessonBlock[]`. `LessonBlock` — размеченное
объединение: `heading`, `text`, `image`, `list`, `quote`, `callout`, `code`.
Рендер — `BlockRenderer`, который сопоставляет тип блока с компонентом.

## Почему
- Верстать заранее неизвестный лонгрид в HTML-строке нельзя: контент должен
  оставаться данными, пригодными для будущего API.
- Новый вид контента (видео, тест, карточка) добавляется одним типом в объединение
  и одним компонентом — экран урока не меняется.
- TypeScript проверит, что для каждого типа блока есть рендер.

## Чем платим
- Данные урока многословнее плоского текста.
- Богатый инлайн-текст (жирный, ссылки) внутри блока придётся либо ограничить,
  либо тянуть парсер markdown.

## Что рассматривали ещё
Хранить урок как markdown-строку — компактнее, но верстать нестандартные блоки
(callout, галерея) в нём неудобно, и нужен парсер уже сейчас.
