# 0001. Vite + React SPA, без Next.js

**Дата:** 2026-08-24
**Статус:** принято

## Контекст
Telegram Mini App открывается в WebView внутри Telegram. Это всегда клиентское
приложение под мобильный экран, без индексации поисковиками и без SEO.
Админки не будет, серверного рендеринга не требуется.

## Решение
Vite + React 19 + TypeScript, собранная статика. Роутинг — react-router-dom
в режиме HashRouter.

## Почему
- Мини-апп грузится один раз и дальше живёт как SPA; SSR не даёт ничего, кроме сложности.
- Статику можно положить куда угодно (Vercel, GitHub Pages, любой CDN) — нужен только HTTPS.
- HashRouter не требует настройки rewrite на хостинге и не ломается при перезагрузке WebView.

## Чем платим
- Первый рендер полностью зависит от JS-бандла: нужен свой скелетон-экран.
- Если позже понадобится публичная витрина курсов в вебе с SEO — это будет отдельное приложение.

## Что рассматривали ещё
Next.js — избыточен: App Router, серверные компоненты и роуты API не нужны там,
где нет ни сервера, ни SEO.
