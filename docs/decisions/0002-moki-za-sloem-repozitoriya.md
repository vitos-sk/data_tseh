# 0002. Данные курсов — моки за слоем репозитория

**Дата:** 2026-08-24
**Статус:** принято

## Контекст
Курсы сейчас придуманные, реальный бэкенд появится позже. Нужно не переписывать
экраны, когда моки заменятся на HTTP.

## Решение
Данные лежат в `src/data/*.ts` как обычные типизированные объекты. Экраны их
не импортируют — они ходят в `src/modules/catalog/catalog.repository.ts`,
все методы которого асинхронные и возвращают Promise.

## Почему
- Экраны с первого дня живут с асинхронностью: есть состояния «грузится» и «ошибка».
- Замена мока на fetch — правка одного файла.
- Типы в `catalog.types.ts` становятся контрактом, по которому потом пишется API.

## Чем платим
- Лишний слой там, где сейчас хватило бы прямого импорта: примерно на час больше работы
  и немного больше кода.
- Искусственная асинхронность у данных, которые доступны мгновенно.

## Что рассматривали ещё
Прямой импорт моков в компоненты — быстрее сейчас, но появление API означает правку
каждого экрана.
